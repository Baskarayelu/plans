# Plans

A group money pot for trips and plans. Friends in different countries join with one fingerprint, fund a shared pot in digital dollars (AUSD on Monad), spend under rules the group sets, and settle up in one tap.

Built for Monad Metropolis, Track 02: Consumer Products & Payments.

## Status (6 Oct 2026)

In build. Specification and live verification of Monad mainnet and AUSD are done. Contracts, relayer, indexer and the Android app are pending, and nothing is deployed to mainnet yet. This README gains setup steps, architecture, "Why Monad", contract addresses, sample transaction hashes and judge access instructions as each part ships.
